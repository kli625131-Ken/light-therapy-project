# 研究者模块功能梳理

## 1. 功能权限

| 功能模块 | 功能点 | 详细描述 |
|---------|--------|----------|
| 认证与授权 | 登录 | 使用管理员账号和密码登录系统 |
| 受试者管理 | 受试者信息管理 | 创建、编辑、删除受试者信息，包括基础信息、分组、主试信息等 |
| 受试者管理 | 分组管理 | 创建、删除分组，将受试者分配到不同分组 |
| 受试者管理 | 受试者详情查看 | 查看受试者的基础信息、治疗记录等 |
| 治疗方案管理 | 方案创建 | 创建多阶段光疗方案，设置每个阶段的亮度、色温和时长 |
| 治疗方案管理 | 方案编辑 | 修改已创建的光疗方案 |
| 治疗方案管理 | 方案删除 | 删除自定义光疗方案 |
| 治疗方案管理 | 方案查看 | 查看所有光疗方案及其详细信息 |
| 治疗记录 | 记录查看 | 查看所有受试者的历史治疗记录 |
| 治疗记录 | 记录详情 | 查看单条治疗记录的详细信息，包括关联的问卷结果 |
| 问卷管理 | 问卷配置 | 创建、编辑问卷模板，支持多种问题类型和评分范围配置 |
| 问卷管理 | 问卷结果查看 | 查看受试者的问卷填写结果 |
| 数据管理 | 数据导出 | 导出单受试者或所有受试者的治疗记录和问卷数据 |
| 数据管理 | 临床报告导出 | 生成受试者临床报告，包含基本信息、治疗统计、详细记录和量表评估结果 |
| 数据管理 | 数据备份 | 备份系统数据 |
| 数据管理 | 数据导入 | 导入备份数据 |

## 2. 操作流程

### 2.1 登录流程
1. 打开光疗系统登录页面
2. 选择「研究者登录」角色
3. 输入管理员账号和密码
4. 点击「登录系统」按钮
5. 系统验证身份，成功后进入受试者管理页面

### 2.2 受试者管理流程
1. 登录系统后，点击左侧导航栏的「受试者管理」图标
2. **受试者列表**：查看所有受试者的基本信息，包括ID、分组、性别/年龄
3. **新增受试者**：
   - 点击「新增账户」按钮
   - 填写受试者信息表单
   - 点击「保存」按钮
4. **编辑受试者**：
   - 点击受试者列表中的「编辑」按钮
   - 修改受试者信息
   - 点击「保存」按钮
5. **删除受试者**：点击受试者列表中的「删除」按钮，确认后删除
6. **查看受试者记录**：
   - 点击受试者列表中的「在线查看记录」按钮
   - 查看该受试者的治疗记录
7. **导出受试者数据**：
   - 点击受试者列表中的「导出记录(含问卷)」按钮
   - 系统生成CSV文件并下载
8. **导出临床报告**：
   - 点击受试者列表中的「导出临床报告」按钮
   - 系统生成HTML格式的临床报告并下载
9. **分组管理**：
   - 点击「管理分组」按钮
   - 在弹窗中输入新分组名称，点击「添加」按钮
   - 点击分组旁的「删除」按钮删除分组

### 2.3 治疗方案管理流程
1. 点击左侧导航栏的「方案配置」图标
2. **方案列表**：查看所有光疗方案，包括名称、总时长、描述和阶段信息
3. **新建方案**：
   - 点击「新建方案」按钮
   - 填写方案名称和描述
   - 添加和配置方案阶段（亮度、色温、时长）
   - 点击「保存」按钮
4. **编辑方案**：
   - 点击方案旁的「编辑」按钮
   - 修改方案信息和阶段配置
   - 点击「保存」按钮
5. **删除方案**：点击方案旁的「删除」按钮，确认后删除

### 2.4 问卷配置流程
1. 点击左侧导航栏的「问卷配置」图标
2. **问卷编辑**：
   - 查看当前问卷模板
   - 编辑现有问题：修改问题内容、类型、选项或评分范围
   - 添加新问题：选择问题类型，点击「添加」按钮
   - 删除问题：点击问题旁的「删除」按钮
3. **问卷模式**：
   - 选择简化模式：仅保存量表标题和最终总分
   - 选择完整模式：保存所有问题和答案
4. **保存配置**：点击「保存配置」按钮，问卷配置更新，下次受试者治疗时生效

### 2.5 数据与备份流程
1. 点击左侧导航栏的「数据与备份」图标
2. **导出所有记录**：点击「导出所有记录」按钮，系统生成包含所有受试者治疗记录和问卷数据的CSV文件并下载
3. **备份数据**：点击「备份数据」按钮，系统生成JSON格式的备份文件并下载
4. **导入数据**：
   - 点击「选择文件」按钮，选择JSON格式的备份文件
   - 点击「导入」按钮，系统导入备份数据
   - 页面刷新后显示导入的数据

### 2.6 退出流程
1. 点击顶部导航栏的「退出」按钮
2. 系统清除登录状态，返回登录页面

## 3. 交互逻辑

### 3.1 登录页面交互
- 切换登录角色时，用户名输入框的占位符和提示文字会相应变化
- 输入错误的账号或密码时，显示错误提示信息
- 点击登录按钮后，系统进行身份验证，验证成功后跳转到受试者管理页面

### 3.2 受试者管理页面交互
- 受试者列表显示ID、分组、性别/年龄和操作按钮
- 点击不同操作按钮（编辑、查看记录、导出记录、导出临床报告、删除）触发相应功能
- 新增/编辑受试者时，弹出表单模态框，包含所有必要字段
- 分组管理通过弹窗实现，支持添加和删除分组

### 3.3 方案配置页面交互
- 方案列表显示方案名称、总时长、描述和操作按钮
- 新建/编辑方案时，弹出表单模态框，包含方案基本信息和阶段配置
- 支持添加、编辑和删除方案阶段
- 方案阶段以可视化方式展示，显示每个阶段的时长、亮度和色温

### 3.4 问卷配置页面交互
- 问卷编辑页面显示当前问卷模板的所有问题
- 支持多种问题类型：评分题、选择题、文本题
- 评分题支持自定义评分范围
- 选择题支持自定义选项（用逗号分隔）
- 支持添加、编辑和删除问题
- 支持切换问卷模式（简化/完整）
- 保存配置后，显示成功提示信息

### 3.5 数据与备份页面交互
- 提供明确的数据导出、备份和导入按钮
- 导出和备份操作后，系统生成相应文件并自动下载
- 导入操作支持文件选择和验证，导入成功后显示提示信息

### 3.6 导航交互
- 左侧导航栏包含「受试者管理」、「治疗记录」、「方案配置」、「问卷配置」、「数据与备份」功能
- 切换导航项时，页面内容相应更新
- 当前活跃的导航项高亮显示

## 4. 界面设计要求

### 4.1 布局设计
- 采用左侧导航栏+主内容区域的经典后台管理系统布局
- 顶部导航栏显示系统名称和退出按钮
- 主内容区域根据当前导航项显示相应内容

### 4.2 视觉设计
- 主色调：靛蓝色系，体现专业性和权威性
- 按钮设计：采用圆角设计，悬停效果明显
- 卡片式布局：内容区域采用卡片式设计，增强视觉层次感
- 图标使用：使用直观的图标增强用户体验

### 4.3 响应式设计
- 适配不同屏幕尺寸，确保在桌面设备上有良好的显示效果
- 左侧导航栏在小屏幕设备上可折叠

## 5. 数据交互

### 5.1 登录数据
- 输入：管理员账号、密码
- 输出：登录状态、用户信息

### 5.2 受试者数据
- 输入：受试者信息表单
- 输出：受试者列表、受试者详情

### 5.3 方案数据
- 输入：方案信息表单、阶段配置
- 输出：方案列表、方案详情

### 5.4 问卷数据
- 输入：问卷模板配置
- 输出：问卷模板、问卷结果

### 5.5 治疗记录数据
- 输入：治疗记录查询条件
- 输出：治疗记录列表、记录详情

### 5.6 数据导出/备份数据
- 输入：导出/备份请求
- 输出：CSV/JSON/HTML文件

### 5.7 数据导入数据
- 输入：JSON备份文件
- 输出：导入状态、更新后的数据

## 6. 异常处理

### 6.1 登录异常
- 输入错误的账号或密码时，显示「研究者账号或密码错误」提示
- 网络连接失败时，显示「网络连接失败，请重试」提示

### 6.2 数据操作异常
- 表单验证失败时，显示相应的错误提示信息
- 数据保存失败时，显示「数据保存失败，请重试」提示
- 数据删除失败时，显示「数据删除失败，请重试」提示

### 6.3 文件操作异常
- 导出文件生成失败时，显示「文件导出失败，请重试」提示
- 导入文件格式不正确时，显示「备份文件格式不正确，缺少必要的数据字段」提示
- 导入文件解析失败时，显示「JSON 解析失败，请检查文件格式是否正确」提示
- 文件读取失败时，显示「文件读取失败，请检查文件是否损坏」提示

## 7. 性能要求

- 登录响应时间：≤1秒
- 页面加载时间：≤2秒
- 数据导出时间：≤5秒（视数据量而定）
- 临床报告生成时间：≤3秒（视数据量而定）
- 数据备份/导入时间：≤10秒（视数据量而定）

## 8. 安全性要求

- 登录密码加密传输
- 敏感数据安全存储
- 严格的权限控制，确保研究者只能访问授权的功能和数据
- 数据备份文件加密处理
- 系统定期自动备份数据
