# 光疗系统项目功能模块梳理

## 1. 项目概述
本项目是一个光疗系统，主要用于精神卫生领域的光疗治疗，包含两个核心角色：受试者和研究者。系统提供光疗方案管理、治疗控制、数据记录、问卷评估等功能。

## 2. 核心功能模块

### 2.1 认证与授权模块
- **登录功能**：支持受试者和研究者两种角色登录
- **角色管理**：区分受试者和研究者权限
- **会话管理**：管理用户登录状态

### 2.2 受试者管理模块
- **受试者信息管理**：创建、编辑、删除受试者信息
- **分组管理**：创建、删除分组，将受试者分配到不同分组
- **受试者详情查看**：查看受试者的基础信息、治疗记录等

### 2.3 治疗方案管理模块
- **方案创建**：创建多阶段光疗方案
- **方案编辑**：修改已创建的光疗方案
- **方案删除**：删除自定义光疗方案
- **方案查看**：查看所有光疗方案及其详细信息

### 2.4 光疗控制模块
- **方案选择**：受试者选择预设光疗方案
- **手动模式**：手动调整亮度和色温
- **治疗过程监控**：实时显示治疗进度和参数
- **治疗控制**：开始、停止治疗

### 2.5 治疗记录模块
- **记录生成**：自动生成治疗记录
- **记录查看**：查看历史治疗记录
- **记录详情**：查看单条治疗记录的详细信息

### 2.6 问卷管理模块
- **问卷配置**：创建、编辑问卷模板
- **问卷发放**：治疗后自动发放问卷
- **问卷填写**：受试者填写治疗反馈问卷
- **问卷结果查看**：研究者查看问卷结果

### 2.7 数据管理模块
- **数据导出**：导出治疗记录和问卷数据
- **临床报告导出**：生成受试者临床报告
- **数据备份**：备份系统数据
- **数据导入**：导入备份数据

## 4. 操作流程与交互逻辑

### 4.1 受试者操作流程
1. 登录系统
2. 进入光疗控制页面
3. 选择预设方案或进入手动模式
4. 开始治疗
5. 监控治疗过程
6. 治疗结束后填写问卷
7. 查看历史治疗记录
8. 退出系统

### 4.2 研究者操作流程
1. 登录系统
2. 管理受试者信息
3. 管理光疗方案
4. 配置问卷模板
5. 查看治疗记录和问卷结果
6. 导出数据或生成临床报告
7. 备份系统数据
8. 退出系统

## 5. 关键交互逻辑

### 5.1 治疗流程交互
1. 受试者选择方案或手动设置参数
2. 点击开始治疗
3. 系统开始计时并控制光疗参数
4. 治疗过程中实时显示进度和参数
5. 治疗结束后自动弹出问卷
6. 受试者填写问卷并提交
7. 系统保存治疗记录和问卷结果

### 5.2 数据导出交互
1. 研究者选择导出类型（单受试者记录、所有记录、临床报告）
2. 系统生成导出文件
3. 研究者下载文件

### 5.3 问卷配置交互
1. 研究者进入问卷配置页面
2. 选择问卷模式（简化/完整）
3. 添加、编辑或删除问题
4. 设置问题类型和选项
5. 保存问卷配置
6. 新配置在下次治疗时生效
