# 受试者模块功能梳理

## 1. 功能权限

| 功能模块 | 功能点 | 详细描述 |
|---------|--------|----------|
| 认证与授权 | 登录 | 使用受试者ID和密码登录系统 |
| 光疗控制 | 方案选择 | 从预设方案列表中选择合适的光疗方案 |
| 光疗控制 | 手动模式 | 手动调整光疗设备的亮度（0-10000 Lux）和色温（2700-6500 K） |
| 光疗控制 | 治疗过程监控 | 实时显示治疗时间、当前阶段、亮度和色温参数 |
| 光疗控制 | 治疗控制 | 开始和停止光疗治疗 |
| 治疗记录 | 记录查看 | 查看本人的历史治疗记录，包括治疗日期、时间、方案、时长和状态 |
| 问卷管理 | 问卷填写 | 治疗结束后填写预设的反馈问卷 |

## 2. 操作流程

### 2.1 登录流程
1. 打开光疗系统登录页面
2. 选择「受试者登录」角色
3. 输入受试者ID和密码
4. 点击「登录系统」按钮
5. 系统验证身份，成功后进入光疗控制页面

### 2.2 光疗治疗流程
1. 登录系统后，默认进入光疗控制页面
2. **选择治疗方式**：
   - **方案治疗**：从推荐方案列表中选择一个方案，点击「开始」按钮
   - **手动治疗**：调整亮度和色温参数，点击「启动手动」按钮
3. **治疗过程**：
   - 系统开始计时，实时显示治疗时间、当前阶段（方案治疗）、亮度和色温
   - 方案治疗时，系统会自动切换到下一个阶段
   - 手动治疗时，可以随时调整亮度和色温
4. **结束治疗**：
   - 方案治疗自动结束，或点击「结束治疗」按钮手动结束
   - 手动治疗点击「结束治疗」按钮结束
5. **填写问卷**：治疗结束后，系统自动弹出反馈问卷
6. **提交问卷**：填写完毕后，点击「提交反馈并退出」按钮
7. **治疗完成**：系统显示感谢页面，可选择「返回主界面」或「安全退出系统」

### 2.3 查看历史记录流程
1. 登录系统后，点击底部导航栏的「历史记录」图标
2. 进入历史记录页面，查看所有治疗记录
3. 每条记录显示治疗日期、时间范围、方案名称、实际时长和治疗状态

### 2.4 退出流程
1. 点击底部导航栏的「退出登录」图标（桌面端）或右上角的退出按钮（移动端）
2. 系统清除登录状态，返回登录页面

## 3. 交互逻辑

### 3.1 登录页面交互
- 切换登录角色时，用户名输入框的占位符和提示文字会相应变化
- 输入错误的ID或密码时，显示错误提示信息
- 点击登录按钮后，系统进行身份验证，验证成功后跳转到光疗控制页面

### 3.2 光疗控制页面交互
- **治疗前**：
  - 显示「设备待机中」状态
  - 方案治疗：显示推荐方案列表，每个方案显示名称、描述、阶段分布和总时长
  - 手动治疗：显示亮度和色温滑块，可调整参数
- **治疗中**：
  - 光效模拟区域根据当前参数显示相应颜色
  - 实时显示治疗时间（格式：MM:SS）
  - 方案治疗：显示当前阶段和总阶段数
  - 显示当前亮度和色温参数
  - 显示「结束治疗」按钮
- **治疗后**：
  - 自动弹出反馈问卷弹窗
  - 问卷填写完成后，显示感谢页面

### 3.3 问卷交互
- 问卷弹窗显示问卷标题和必填提示
- 根据问题类型显示不同的输入控件：
  - 评分题：显示滑块控件，可在指定范围内选择分值
  - 选择题：显示选项按钮，可单选
  - 文本题：显示文本输入框，可输入文字
- 问卷填写完成后，点击「提交反馈并退出」按钮提交问卷

### 3.4 历史记录页面交互
- 记录按时间倒序排列（最新记录在前）
- 每条记录显示关键信息，包括日期、时间、方案、时长和状态
- 支持滚动加载更多记录

### 3.5 导航交互
- 移动端底部导航栏包含「光疗控制」和「历史记录」两个主要功能入口
- 桌面端左侧导航栏包含「光疗控制」、「历史记录」和「退出登录」功能
- 切换导航项时，页面内容相应更新

## 4. 界面设计要求

### 4.1 布局设计
- 移动端：采用底部导航栏设计，主内容区域自适应屏幕大小
- 桌面端：采用左侧导航栏+主内容区域的经典布局

### 4.2 视觉设计
- 主色调：蓝色系，体现科技感和专业性
- 光效模拟区域：根据当前参数实时显示颜色变化，增强用户体验
- 按钮设计：采用圆角设计，悬停效果明显，操作反馈及时

### 4.3 响应式设计
- 适配不同屏幕尺寸，包括手机、平板和桌面设备
- 确保在各种设备上都能正常操作和查看信息

## 5. 数据交互

### 5.1 登录数据
- 输入：受试者ID、密码
- 输出：登录状态、用户信息

### 5.2 治疗数据
- 输入：选择的方案ID或手动参数
- 输出：治疗状态、实时参数、治疗记录

### 5.3 问卷数据
- 输入：问卷答案
- 输出：问卷提交状态

### 5.4 历史记录数据
- 输入：受试者ID
- 输出：治疗记录列表

## 6. 异常处理

### 6.1 登录异常
- 输入错误的ID或密码时，显示「受试者ID或密码错误」提示
- 网络连接失败时，显示「网络连接失败，请重试」提示

### 6.2 治疗异常
- 治疗过程中网络中断时，系统尝试本地缓存数据，恢复连接后同步
- 设备连接异常时，显示「设备连接失败，请检查设备」提示

### 6.3 问卷异常
- 问卷提交失败时，显示「问卷提交失败，请重试」提示
- 本地缓存问卷答案，确保数据不丢失

### 6.4 数据加载异常
- 历史记录加载失败时，显示「数据加载失败，请重试」提示
- 方案列表加载失败时，显示「方案加载失败，请重试」提示

## 7. 性能要求

- 登录响应时间：≤1秒
- 治疗参数更新频率：≥1次/秒
- 页面切换响应时间：≤500毫秒
- 数据加载时间：≤2秒

## 8. 安全性要求

- 登录密码加密传输
- 治疗数据和问卷数据安全存储
- 受试者只能查看本人数据，无法访问其他受试者数据
- 系统定期自动退出登录，确保设备安全
