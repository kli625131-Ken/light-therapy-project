# 光疗系统项目开发需求文档

## 1. 项目概述

### 1.1 项目背景
本项目是一个光疗系统，主要用于精神卫生领域的光疗治疗，包含两个核心角色：受试者和研究者。系统提供光疗方案管理、治疗控制、数据记录、问卷评估等功能。

### 1.2 项目目标
- 完成前端从React到Vue3的架构迁移
- 设计并实现MySQL数据库
- 开发后端Java服务
- 实现前后端API对接与联调
- 保证系统功能完整性和UI一致性

### 1.3 技术栈

| 方向 | 技术栈 |
|------|--------|
| 前端 | Vue 3 + JavaScript + Vite + 本地CSS |
| 后端 | Java 8 + Spring 4.3.x + Hibernate 3.2.x + MySQL 8.0.x |
| 数据库 | MySQL 8.0.x |

## 2. 功能模块清单

### 2.1 核心功能模块

| 功能模块 | 功能点 |
|---------|--------|
| 认证与授权 | 登录、角色管理、会话管理 |
| 受试者管理 | 受试者信息管理、分组管理、受试者详情查看 |
| 治疗方案管理 | 方案创建、方案编辑、方案删除、方案查看 |
| 光疗控制 | 方案选择、手动模式、治疗过程监控、治疗控制 |
| 治疗记录 | 记录生成、记录查看、记录详情 |
| 问卷管理 | 问卷配置、问卷发放、问卷填写、问卷结果查看 |
| 数据管理 | 数据导出、临床报告导出、数据备份、数据导入 |

## 7. 开发规范

### 7.1 代码规范
- 前端：遵循Vue3官方编码规范，使用ESLint + Prettier进行代码检查和格式化
- 后端：遵循Java编码规范，使用Lombok简化代码，代码注释清晰
- 数据库：遵循数据库设计规范，合理设计索引和外键关系

### 7.2 命名规范
- 前端：组件命名使用PascalCase，文件命名使用kebab-case
- 后端：类名使用PascalCase，方法名和变量名使用camelCase
- 数据库：表名使用snake_case，字段名使用snake_case

### 7.3 文档规范
- 组件文档清晰完整
- API文档详细
- 开发文档及时更新
- 提交信息使用Conventional Commits规范
